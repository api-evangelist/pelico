# Pelico

> Pelico is the orchestration platform for manufacturing and MRO execution — the system that makes production plans actually happen despite frequent supply chain disruptions. It connects, cleans and enriches data from every system, function and site into a single operational truth across multi-level BOM, multi-plant environments, then uses domain-specific AI agents to anticipate disruptions, determine upstream and downstream impact, simulate recovery options against KPIs, and orchestrate cross-functional action with humans in the loop.

This llms.txt was generated by the API Evangelist enrichment pipeline from Pelico's public web surface (probed 2026-08-17). Pelico does not publish a public developer API, developer portal, API reference, or OpenAPI. It markets an API — the platform page states Pelico offers "APIs to ingest new data sources and push actions into existing enterprise systems without disruption" — but that surface is delivered inside an enterprise engagement and is reachable only through a sales conversation. Every conventional API host (api., docs., developers., app., mcp.pelico.ai) is NXDOMAIN, and no /.well-known/ discovery document, MCP endpoint, GraphQL endpoint, or agent card is served on any Pelico host.
