# Pelico

> Pelico is a manufacturing orchestration platform that bridges the execution gap between planning and real-world production. It unifies data from suppliers, production, inventory, quality, maintenance, and customers into a single operational view across multi-level BOMs and multi-plant networks, then uses domain-specific AI agents to monitor disruptions, simulate recovery options, and keep cross-functional teams synchronized in real time.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public Pelico web surface. Pelico does not publish a public developer API, developer portal, or OpenAPI at this time; its API surface is enterprise integration only (ingesting data sources and pushing actions into ERP systems such as SAP, Oracle, and Infor).
